# Multi-Tenant Data Isolation & Security Architecture

**Owner:** Frank Castle & Bob Martinez  
**Status:** Approved  

## Logical Isolation Mechanisms
Project Phoenix utilizes a shared-database, pooled-schema model with mandatory row-level security (RLS) policies.

1. **Row-Level Security (RLS):**
   - Every SQL query generated by the application sets the session variable `SET LOCAL app.current_tenant_id = '...'`.
   - PostgreSQL RLS policies enforce `USING (tenant_id = current_setting('app.current_tenant_id')::uuid)`.
2. **Redis Namespace Separation:**
   - Keys are formatted as `tenant:{tenant_id}:{resource}:{id}`.
3. **Kafka Partitioning:**
   - Kafka record keys contain the tenant ID to prevent cross-tenant message interleaving within partitions.
